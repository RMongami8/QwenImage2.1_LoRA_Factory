データセット / Dataset

画像と同名の .txt に自然文キャプションを置きます（例: img01.png + img01.txt）。解像度は混在可（バケット処理）。
Put a same-named .txt natural-language caption beside each image. Mixed sizes are fine.

キャプション / Captions

🤖 Gemma 自動キャプション / Auto-captioning

Gemma-4 は事前にローカルへ保存してください: hf download google/gemma-4-E4B-it --local-dir "C:\models\gemma-4-E4B-it"
Download Gemma once (license acceptance + hf login required). The app only reads the local folder.
編集は自動保存されます / edits autosave

学習設定 / Configuration

diffusion_models / text_encoders / vae を含むフォルダ(ComfyUI の models も可)

毎回同じseedで生成するので、チェックポイント間・強さ間を公平に比較できます。強さ比較は1回あたりの生成枚数(=プロンプト数×強さの数)が増えます。縦長学習なら 576×1024 や 736×1312 など。
